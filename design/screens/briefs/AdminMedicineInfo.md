## Layout

- Page header: "Medicine information", the rule (only what a pharmacist approves reaches people), and **Import CSV** (`upload`, super admin only).
- `shield-check` note for anyone who cannot approve ("Only a pharmacist can approve").
- Search (`search`) and filter tabs: To review · Fully approved · All.
- **Medicines** table: medicine (brand + composition), form · schedule, approved "n of 11", status pill (All approved · Partly approved · Changed since approval (amber) · Imported · hidden · Off), row action **Open** (`pencil`). Empty state with `pill`. Foot note `alert-triangle`: never paste AI-written text.
- **Medicine dialog**: notes (`shield-check` approve rule, `info` identity fields come from the medicine list); one card per field with its state pill, the value (identity) or a text area (monograph; age groups as `BAND:FORM:strength` lines), Source and Source link, "Approved by a pharmacist on …", **Save** (`pencil`), **Approve** (`check-circle`, pharmacists only; off until saved and sourced), **Take off** (`rotate-ccw`). **History** (`file-text`): every import, edit, approval and take-off with who (you / role) and when.
- **Import dialog**: CSV file, dataset name, licence reference (required), source link; the column list; result counts and row errors.

## States

Loading · empty · error with retry · saving · approve refused (changed meanwhile, 409; source missing, 422) · import result with row errors.

## Rules

Every change is audited (`care_medicine_info_events`, `care_workflow_audit`). Only pharmacists approve; super admins edit, import and take off. Imports land unreviewed. Nothing is generated by an AI.
