# Animated icons and illustrations

Lottie animations from the licensed packs (licences: `docs/licences/animation-packs.md`), recoloured to
Student Kare tokens and drawn only through `<AnimatedIcon>` and `<AnimatedIllustration>` from
`src/design-system/icons`.

## Rules
- **Only these names.** Every animation is listed in `lottie.config.json` and, after a build, under
  `animated` in `design/icons/icon-manifest.json`. `check-icons` fails a screen that names an animation
  the manifest does not have, and a mapped screen listed for an animation that does not use it.
- **Tokens only.** The build maps every colour in the artwork to a token role and writes the role into
  the file (`"sk"`); the component swaps in the light or dark value at run time. Icons are one ink, set
  with the `color` prop like `<Icon>`. Artwork never uses `danger*`: red appears only where the caller
  passes a danger colour (errors, SOS), and only on entries marked `danger: true`.
- **Motion rules (DESIGN.md §3).** Reduced motion (`prefers-reduced-motion` / iOS and Android setting)
  shows a still frame (`rest`). Loops stop off screen, when the tab or app is in the background and
  when unmounted. Nothing animates on clinical content, and nothing celebrates the body: success
  motion is a single draw of a tick.
- **Charts are decoration.** `loop-chart-*` appear only in loading or empty states, never where a
  person could read them as their data. Their packs' number layers are stripped at build time.
- **Never redistribute.** Only the processed JSON of the animations in use is committed. The packs,
  `.aep`, `.ai`, `.fig`, previews and zips stay out of the repo and are never served as downloads.

## Variants
- `variant="flat"` (default): the drawing in the ink colour.
- `variant="3d"`: the drawing in white on a raised tile that matches `<Icon3d>`: a service-hue gradient
  lit from the top left, an inner highlight (`action-highlight`), a soft drop shadow (`shadow.float`)
  and a ground shadow, with a gentle tilt toward the pointer on hover and a press-in on press. No tilt
  under reduced motion.

## Rebuilding
```
node scripts/icons/build-lottie.mjs --packs <folder with the unzipped packs>
node scripts/icons/build-icons.mjs
```
Sizes come from the `size.anim-*` tokens.

## Bundle budget (measured 2026-10-23 against main)
- **Web, initial load:** +16.5 KB raw / +5.0 KB gzip (the components, the palette swap and the name
  registry). lottie-web's light SVG player (165 KB / 47 KB gzip) and every animation are separate
  chunks, fetched the first time an animation scrolls into view.
- **Web, lazy chunks:** 21 icons 114 KB (12 KB gzip) in all, the three scenes 13–17 KB gzip each, the
  three chart loops 1–2 KB gzip each.
- **Native (expo export, Android, Hermes):** 7.29 MB → 8.33 MB (+1.04 MB, +241 KB gzip). Most of it is
  Hermes compiling the 27 JSON objects to bytecode; the three scenes are about two thirds. If that
  matters, ship the scenes as strings parsed on first use, or leave them web-only.
