Type

Manrope stands in for Gilroy and does both headings and interface. IBM Plex Mono is a deliberate addition to the one-family rule, carrying anything a machine printed — values, units, ranges, dates, IDs. That last rule is what makes a report readable out loud to a doctor.

Indic scripts get +2
Add 2px to lineHeight on Hindi and Telugu for mātrās and ascenders. Design in Telugu first; it sets 15–25% longer.
Numbers stay Latin, and tabular
Values, units, dates and IDs render in Plex Mono in every language, never in Devanagari or Telugu numerals.
Scales to 200%
Do not disable font scaling. Every screen must survive 200% without clipping — test the emergency card first.

Register the fonts by PostScript name
React Native resolves fontFamily by file name, not by family plus weight. Ship the static cuts and reference them exactly as above.
Manrope stands in for Gilroy
Gilroy is the licensed family; Manrope is the named substitute. Ship static Medium and SemiBold cuts and keep the token names. Swapping later is a font-file change, not a code change.
One theme, three surfaces
Student app, camp station and clinician console share this file. The station overrides only hit targets and contrast floors.

Light and dark

Sky is written light-first, because a record should read like paper. But students read at midnight in a dark hostel room, so a dark theme ships too and the phone decides. Every page here follows your system setting — switch your OS appearance and this sheet changes with it.

The accents cannot simply carry over. Clinical Cyan is 2.9:1 on Pearl and Mint Vital is 1.6:1 — both illegible as text — so each accent has a dark-theme sibling lifted until it clears 4.5:1 — Iris Pulse becomes #00b1ff, amber becomes #ffb020, and the reward violet lifts to #2ee9ff. Same token, same meaning, two values.

The ink band inverts too
The hard light-to-dark break is a signature, so it flips rather than disappears: the campus band is ink on a light page and paper on a dark one. A dark section on a dark canvas would lose the cut entirely.
Icons inherit, art is themed
Every icon stroke is currentColor, so it follows the text beside it. Line art carries an explicit --art, which deepens to #8f86d8 on Pearl — Lilac Mist is only 2.1:1 there.
Two surfaces ignore the theme
The camp station stays white in both themes for glare and for the 7:1 floor, and the emergency card stays red. Neither is a brand decision — one is read in sunlight, the other by a stranger in a hurry.
import { useColorScheme } from 'react-native';

export const useTheme = () => {
  const scheme = useColorScheme();         // 'dark' | 'light' | null
  return scheme === 'dark' ? dark : light; // light is the default
};

Rules that outrank the tokens

A screen can use every value on this page correctly and still be wrong. These are the ones to check in review.

No score, ring or gauge
No health score, no BMI dial, no percentile, no streak. Body metrics are recorded and referred, never rated.
Money never touches the body
Points, offers and rewards never appear on a screen containing a clinical value.
Every clinical view ends in a human
Book, escalate or see a doctor. A screen showing a value with no next step is unfinished.
The source is always one tap away
Every clinical number came off a document. View original is present on every record detail.
Ranges come off the printout
Never a model-supplied or app-supplied reference range. If it could not be read, show the scan.
Nothing near mental health
No badge, count, streak or reminder on any counselling or crisis surface.
