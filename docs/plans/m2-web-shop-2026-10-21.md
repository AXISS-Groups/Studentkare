# Web shop to Mobile 2.0 — inventory and where each flow lands (2026-10-21)

Krishna asked to merge the studentkare.co/shop flows into the new UI. At phone width (≤ 430 px) a
signed-in student already gets Mobile 2.0 Medicines (M2Medicines) and the new medicine page
(M2Product). This plan covers tablet and desktop widths: `/shop` and `/checkout` for a signed-in
student (student web shell: `WebShopView`, `WebSearchResultsView`, `WebProductView`,
`WebCheckoutView`) and for a visitor or another role (`CareScreen` → `LiveMarketplaceScreen`).

Tier 2, except the medicine page, which keeps M2Product's approved Tier 1 rules (no unreviewed
medicine information; a prescription medicine is never added to the cart and routes to a pharmacy).

Inventory taken at 1440 px before any change. "Signed out" = the public marketplace
(`LiveMarketplaceScreen shop`); "Student" = the student web shell pages.
