# Doctor consults (/care) to Mobile 2.0 above phone width — inventory and where each flow lands (2026-10-21)

Ticket K1 (`docs/tickets/PROMPTS.md`): bring `/care` (doctor consults and care services) above phone
width onto the Mobile 2.0 design, the way #196 did for `/shop` and `/checkout`
(`docs/plans/m2-web-shop-2026-10-21.md`). At phone width a signed-in student already gets Mobile 2.0
Doctor consults (M2Consults: `M2ConsultsView`, `M2ConsultsRoute`, `ConsultsViewModel`). This plan
covers tablet and desktop widths for the signed-in student (student web shell) and `/care` at every
width for a visitor or another role (public site header and footer), which today all draw the old
`LiveMarketplaceScreen care`.

Rules followed: `CLAUDE.md`, `AGENTS.md`, `DESIGN.md`, `design/README.md`, and the #196 pattern. The
ticket referred to `docs/build/RULES.md`; that path does not exist (#197 dropped it because
`docs/build/` is git-ignored). The same rules landed afterwards as `docs/tickets/RULES.md` (#199),
which this work also follows; `CLAUDE.md` / `AGENTS.md` / `DESIGN.md` win on any conflict.

## Built (2026-10-21)

Screenshots (API intercepted, reduced motion, "Low mood" picked so the crisis note shows) are in
`docs/plans/screenshots/m2-web-care/`: `<1440|1024|390>-<light|dark>-<signed-in|signed-out>.jpg`,
plus `before-1440-light-signed-in.jpg` (the old marketplace, for this inventory). #196 committed no
screenshots, so this folder is new. At 390 px the signed-in student is the unchanged M2Consults
phone board; the visitor is the new page in the public frame.

Differs from the picture (M2Consults is a phone board; this is its wide form), and why:
- Doctor cards sit in a grid, not a sideways rail, and have a Details button that fills the sticky
  "Your consult" summary; Book is the same as on the phone.
- The summary and "Pay ahead at checkout" are new: they carry the old desktop's detail dialog and
  its cart → checkout → pay path (rows 11–13), which the phone board does not have.
- No back arrow in the hero: the student shell and the public header carry navigation. The pill nav
  (home, box, Ayush orb) is the phone frame's; on the web the shell's Ayush button stands in.
- "[n] doctors online", "[n] yrs", languages and "Reg. no." are not shown (no data), as on the phone.
