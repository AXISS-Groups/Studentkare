Dev notes and edge cases
The parts of this flow that are decisions rather than layout.
WRITE ORDER
File first, read second
The record row is written and rendered before OCR is queued. If the app is killed mid-read, the record still exists with its pages.
CONFIDENCE
Below threshold means blank
A low-confidence value is never shown as a value, not even greyed. It renders as needs-review with the cropped scan. No guessed digits anywhere.
RANGES
No range, no bar
If the lab did not print a range, show the value alone. Never substitute a standard range from a table — that is a fabricated clinical claim.
OFFLINE
Queue depth is always visible
A persistent banner, not a toast. Capture never blocks on connectivity; pages are written to local storage first and uploaded opportunistically.
PRIVACY
Strip identity before inference
Name, phone, ABHA and roll number are removed before the page text reaches any model. Region-locked, zero retention, no training.
EDGE CASES
The ones that will happen
Someone else's report photographed by mistake · a 40-page discharge summary · handwritten prescription · a report in Telugu with Latin values · duplicate of an existing record · a photo of a phone screen showing a report.
